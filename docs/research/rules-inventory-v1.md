# Rules inventory: UNIversum v1

Research for #5, part of the map #1 (UNIversum v2 modernization). This catalogue lists every game rule as the v1 code plays it, and it is the yardstick for feature parity. The code is the rules reference: nothing here comes from the thesis PDF. Terms follow `GLOSSARY.md` (Room, Lobby, Player, Guest, Board, Field). Terms the glossary does not have yet are listed under [Glossary candidates](#glossary-candidates).

Rules are numbered **R1…R80** so later tickets can cite them. A "Flag" (F1…F30) marks a rule that is ambiguous, where the client and server disagree, or that looks buggy. Flags are recorded here and not fixed.

How v1 is built, because it explains many of the flags: every browser in the Room runs the whole rules engine (the Redux slice plus component effects). The active Player's browser acts and sends a socket event, the server relays it unchanged to the rest of the Room (`index.ts:84-226`), and every other browser replays the same reducer locally. The server holds no game state after the initial deal (`GameSystem.ts:13-57`). ADR-0001 reverses this for v2.

### 4.1 Normal Field pricing formula

| #   | Rule                                                                                                                                                                         | Source                                           |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| R25 | A Normal Field has levels 0 (unbuilt / unowned) to 4 (called _emelet_, "floor").                                                                                             | `calcPrice.js:62-73`, `BuyComponent.jsx:425-428` |
| R26 | Base price `B = 200,000 + (n − 1) × 20,000`, where _n_ is the Field's 1-based position among the Normal Fields (Veszprém n=1 … Cambridge US n=20).                           | `calcPrice.js:58-59`, `:75-82`                   |
| R27 | Cumulative value at level L: `toBuy(L) = B + (L − 1) × B × s(L)`, with s = 0.2, 0.2, 0.3, 0.4 for L = 1…4. This works out to 1.0 B, 1.2 B, 1.6 B, 2.2 B. Level 0 is worth 0. | `calcPrice.js:62-73`, `:82`                      |
| R28 | Rent (_tandíj_, "tuition") at level L: `toBuy(L) × r(L)`, with r = 0.55, 0.70, 0.85, 1.00.                                                                                   | `calcPrice.js:70-73`, `:83`                      |
| R29 | **Monopoly:** if one owner holds every Field of the group, rent is ×1.4.                                                                                                     | `calcPrice.js:13-34`, `:83`                      |
| R30 | Selling to the bank pays 90% of `toBuy(L)`; buying out another Player's Field costs 200% of `toBuy(L)`.                                                                      | `calcPrice.js:88-89`                             |
| R31 | Upgrading from level a to level b costs `toBuy(b) − toBuy(a)`.                                                                                                               | `BuyComponent.jsx:42-49`, `:527`                 |

## Glossary candidates

Domain terms the code uses that `GLOSSARY.md` lacks (not edited here):

- **Normal Field** (city / university Field): a buildable Field with levels 1–4.
- **Level** (_emelet_, "floor"): how far a Normal Field is built up, 0–4.
- **Group** and **Monopoly**: Normal Fields that share a `groupId`; one owner holding the whole group gets ×1.4 rent.
- **Rent / Tuition** (_tandíj_): what a Player pays the owner when landing on their Field. The UI says "Tandíj".
- **Buyout**: buying another Player's Field at 200% of its value.
- **Museum** and **Super-monopoly**: a special Field; owning all four wins the game.
- **Chance card** (_Esély_): one of 3 cards drawn on a Chance Field.
- **Tax** (_Adó_): 10% of property value.
- **Quarantine** (_Karantén_) and **Quarantine round**: three missed turns.
- **PCR test**: releases a Player from quarantine; it can be held (from a card) or bought (200,000).
- **Doubler** (_Talár_, "gown"; the panel says "you graduated"): the single token that multiplies one Field's rent.
- **Erasmus**: a corner Field that lets a Player travel to a chosen Field.
- **Round bonus**: the 250,000 paid for passing Start.
- **Turn timer** and **Timeout penalty**: the per-turn countdown and its 10% / forced-sale punishment.
- **Minute limit / end time**: the Room's game length (15/30/50 min).
- **Auto-sell**: automatic cheapest-first sale to cover a shortfall.
- **Bankrupt** (_csőd_): out of the game.
- **Colour code / seat**: a Player's index 0–3, which fixes turn order and colour.
- **Room code**: the 6-digit join code.
